# Duve3Utils

a small utility kit with cool features! <3

also look at:

[ElytraPitch](https://modrinth.com/mod/elytrapitch) - for elytra positioning and tilting\
[ChatTools](https://modrinth.com/mod/chat-tools) - for chat automation

^^^ these tools replace features that were removed from this tool

This tool contains currently only two things:
- NightVision - instead of full bright, it applies nightVision (good for shaders)
- AntiDrop - prevent accidentally dropping items not on a certain list
